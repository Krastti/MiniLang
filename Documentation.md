# MiniLang

MiniLang — небольшой учебный язык программирования с интерпретатором на Java. Проект показывает, как исходный текст превращается в токены, как парсер собирает из них дерево программы и как интерпретатор выполняет инструкции из этого дерева.

## Быстрый старт

Для сборки нужны JDK 21 и Maven. Из корня проекта выполни:

```bash
mvn compile
java -cp target/classes com.krastti.minilang.Main examples/main.mini
```

[Пример](examples/main.mini) сохраняет возраст в переменной и выводит `19.0`. Чтобы выполнить свою программу, передай путь к её файлу `.mini` вместо `examples/main.mini`.

## Синтаксис

```text
remember age = 19
remember nextAge = age + 1
print nextAge
print nextAge >= 18
```

Программа выведет `20.0` и `true` на отдельных строках.

- `remember имя = выражение` вычисляет и сохраняет значение переменной.
- `print выражение` вычисляет и выводит значение. Каждая инструкция начинается с новой строки.
- Доступны арифметические операции `+`, `-`, `*`, `/` и числовые сравнения `<`, `<=`, `>`, `>=`, `==`, `!=`. Арифметика вычисляется до сравнений. Круглые скобки позволяют задать порядок вычислений.

Строковые литералы, условия `when … otherwise` и циклы `repeat` пока в планах.

## Тесты

Команда `mvn test` запускает тесты лексера, парсера и интерпретатора.
